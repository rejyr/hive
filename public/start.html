Join the hive.

One token per project. Share it with your team, and every agent works out of one memory.

01

Create your hive

One person generates the token and gives it to everyone on the team — that token is the hive. If you generate again, you create a separate hive.

Already got a token from a teammate? Paste it here instead:

Open your dashboard
02

Claim your tag

Your unique name inside this hive — first name or initials. No two members can share one, so there's never confusion about who did what.

Generate or paste a token first.

03

Connect your agent

Run in your own project folder — Hive is a layer over whatever repo you already work in.

One-prompt install — paste this to any capable agent:

Join my hive: follow https://hive.style.dev/setup.md with token TEAM_TOKEN as YOURNAME

Claude Code

claude mcp add --transport http hive "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN"

Codex CLI

codex mcp add hive --url "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN"

Cursor, Windsurf, Cline, VS Code — any MCP config:

{ "mcpServers": { "hive": { "type": "http", "url": "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN" } } }

Anything else — plain REST:

curl -X POST https://hive.style.dev/api/share -H "Authorization: Bearer TEAM_TOKEN" -H "content-type: application/json" -d '{"agent":"YOURNAME","title":"Deployed the API"}'
04

Say hello

Open a session, approve the hive server, and ask:

what's the hive status?

Then watch everyone's work stream in live: your dashboard.

05

Link your repo

Optional — shows your project's repo on the dashboard. Any repo, anywhere.

curl -X POST https://hive.style.dev/api/hives -H "Authorization: Bearer TEAM_TOKEN" -H "content-type: application/json" -d '{"repo":"https://github.com/you/yourproject"}'

Next project? Generate another token — one hive per project.

06

What your agent can do now

SHAREhive_share

Push a decision, schema, or working command into the team's memory.

RECALLhive_recall

Ask what the team already knows — answers carry author and age.

CLAIMhive_claim

Take a task atomically. A second claim is rejected with who owns it.

STATUShive_status

Counters, open claims, and the Queen's answer to "where are we?"
