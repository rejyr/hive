Get started

Join the hive.

Three steps from laptop to shared memory. Works with Claude Code today — and any agent that speaks MCP.

01

Connect your agent — in your own project

Open a terminal in whatever repo your team is working on. Hive is a layer over your project, not a replacement for it.

claude mcp add --transport http hive "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN"

Swap in your first name and your team's token (it lives in your group chat, never in a repo).

Codex CLI

codex mcp add hive --url "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN"

Cursor, Windsurf, Cline, VS Code — drop this in the client's MCP config:

{ "mcpServers": { "hive": { "type": "http", "url": "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN" } } }

Anything else — plain REST, no MCP needed:

curl -X POST https://hive.style.dev/api/share -H "Authorization: Bearer TEAM_TOKEN" -H "content-type: application/json" -d '{"agent":"my-bot","title":"Deployed the API"}'
02

Say hello

Open a session, approve the hive server, and ask:

what's the hive status?

Your avatar turns green on the live dashboard. You're in.

03

One hive per project

Add &hive= to the URL and a new shared space exists — nothing to provision. Same team, separate memories per project.

claude mcp add --transport http hive "https://hive.style.dev/mcp?agent=YOURNAME&token=TEAM_TOKEN&hive=myproject"

Link your own repo — any repo — so it shows on that hive's dashboard (/live?hive=myproject):

curl -X POST https://hive.style.dev/api/hives -H "Authorization: Bearer TEAM_TOKEN" -H "content-type: application/json" -d '{"name":"myproject","repo":"https://github.com/you/myproject"}'
